# ついでにスポット — はじめてガイド（v1.0.0）

行ってみたいけれど、そのためだけに出かけるほどではない場所。
留めておくと、近くを通ったときに知らせます。

## 1. 入れる

スマホのブラウザで次を開き、ダウンロードしたファイルをタップします。

```
https://github.com/cloud42-labo/serendipity-spot/releases/download/latest/app-release.apk
```

「提供元不明のアプリ」の確認が出たら、ブラウザに対して許可してください（初回のみ）。

このURLは常に同じで、中身だけが最新版に差し替わります。ブックマークしておけば、
次からはここを開くだけで更新できます。

> **すでに古い版が入っている場合**
> `v0.11.x` 以前が入っているときは、署名が変わっているため上書きできません。
> 一度アンインストールしてから入れ直してください。スポットはスプレッドシート側に
> あるので、ログインし直せば元に戻ります。

**Google Play ストアには出していません。** 作者と、その家族・友人が使うための
アプリです。利用者側で Google Cloud の設定をする必要はありません。

## 2. 最初の起動

起動すると、順に許可を求められます。

| 聞かれるもの | 選ぶもの |
| :--- | :--- |
| 位置情報 | アプリの使用時のみ許可 |
| バックグラウンドの位置情報 | **常に許可** |
| 通知 | 許可 |

**「常に許可」が要点です。** ここが「使用中のみ」だと、アプリを閉じている間に通知が
届きません。仕組み上そうなっており、アプリ側では回避できません。

あとから変えるには「設定」→「アプリ」→「ついでにスポット」→「権限」→「位置情報」。

続けて「Googleでログイン」を押し、アカウントを選びます。
**求められる権限は1つだけ**で、「このアプリで使用する Google ドライブ上の特定の
ファイルのみの参照、編集、作成、削除」です。あなたのドライブに
`Serendipity Spot` という名前のスプレッドシートが自動で作られ、そこがスポットの
保管場所になります。**ドライブの他のファイルは見えません。**

## 3. スポットを登録する

**方法は3つあります。**

**名前で探す**
上部バーの虫めがねをタップ →「海浜幕張駅」「〇〇公園」など入力 → **キーボードの検索キー**
（または右の虫めがね）で検索 → 候補を選ぶと、地図に薄い旗が立ちます。その旗をタップすると
登録画面が開きます。名前は入力済みなので、メモだけ書いて保存。

**地図で指す**
名前のない場所（公園のあの辺、など）は、地図を直接タップします。名前を自分で付けます。

**「＋」で中心に置く**
右下の「＋」を押すと、**地図の中央（照準の位置）**に登録できます。地図を動かして
狙いを合わせてから押してください。細かい位置を指で狙うのが難しいときに便利です。

メモは「なぜ気になったか」を書いておくと、通知が来たときに役立ちます。
店名だけだと、半年後に理由を思い出せません。

## 4. 通知が来たら

登録した場所の**半径150m以内に外から入る**と、アプリを閉じていても通知が届きます。
通知にはスポットの名前とメモが出ます。

**通知をタップすると**アプリが開き、その場所に地図が寄って、
**現在地からそこまでの徒歩ルートと距離・所要時間**が表示されます。
「歩いて8分なら寄ろう」の判断がその場でできます。

寄るかどうかは、その場で決めてください。**寄らなくても構いません。**
このアプリは達成率も連続記録も数えません。

### 通知について知っておくこと

- **すぐには鳴りません。** 数十秒から数分かかります。省電力のため、Android が位置情報を
  まとめて処理するためです
- **すでに中にいる状態では鳴りません。** 一度外に出て、また入ったときに鳴ります
- **同じ場所は3時間空きます。** 毎日通る場所に登録しても、何度も鳴ることはありません
- **見逃しても、2分後にもう一度鳴ります。** その場に留まっている場合だけ、1回に限って
- **サイレントモードだと鳴りません。** 端末側の設定です。通したい場合は
  「設定」→「音とバイブレーション」→「サイレントモード」→「アプリ」で
  ついでにスポットからの通知を許可してください

## 5. 一覧・編集・削除

画面下端の帯を上に引き上げると、登録済みスポットの一覧が出ます。

| 操作 | できること |
| :--- | :--- |
| 項目をタップ | その場所へ地図が移動する |
| 人型のアイコン | ストリートビューで周りの様子を見る |
| 鉛筆のアイコン | 名前とメモを書き換える |
| ゴミ箱のアイコン | 削除する（確認あり） |

削除するとスプレッドシートからも消えます。

### 登録できる数について

見出しに「登録スポット（7 / 100）」のように出ます。

**100 は「通知できる数」の上限**で、Android 側の制限です。101件目以降も登録も一覧表示も
できますが、**古い方から順に通知の対象外**になります。上限に近づいたら、
行かなくなった場所を削除してください。

## 6. データについて

スポットは**あなた自身の Google ドライブ**にあります。運営側のサーバーはありません。

- ドライブで `Serendipity Spot` を開けば、中身をそのまま見られます
- スプレッドシート上で直接編集しても構いません（アプリを開き直すと反映されます）
- アプリを消してもデータは残ります
- **アプリがアクセスできるのは、このアプリが作ったファイルだけです。** ドライブ全体は見えません
- 位置情報は端末の中だけで使われ、どこにも送信されません

いつでも [Googleアカウントのアクセス権限管理](https://myaccount.google.com/permissions)
からアクセスを取り消せます。

## 7. うまくいかないとき

| 症状 | 見るところ |
| :--- | :--- |
| 通知が来ない | 位置情報が「常に許可」か。通知が許可されているか。サイレントモードでないか |
| 通知は来るが気づかない | サイレントモードの割り込み許可（上の「通知について知っておくこと」） |
| 地図が灰色 | 通信できているか |
| 現在地が動かない | **位置偽装アプリを使った後、解除し忘れていないか**（開発者向けオプション →「仮の現在地情報アプリを選択」→「なし」） |
| 更新できたか分からない | 下部一覧の「診断」の横にバージョンが出ます |

下部の一覧を一番下まで引き上げると「**診断**」があります。

- **バージョン** — 今入っている版
- **登録** — ジオフェンスをいくつ登録できているか
- **受信** — 最後に位置イベントを受け取った時刻
- **最後の操作** — 直前のタップが地図に届いたか、旗に当たったか
- **テスト通知** — 通知が出せるかその場で確認できます
